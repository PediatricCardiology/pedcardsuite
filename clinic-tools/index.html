Warfarin TTR

Test dateINR
Paste a list instead

One line per test: date, INR. Example: 05/01/2026, 2.4

Method: Rosendaal linear interpolation (Thromb Haemost 1993;69:236), the standard used in anticoagulation trials. INR is assumed to change in a straight line between two tests; each day gets an interpolated value, and TTR = days in range ÷ total days. Data stay on this device only; use study IDs, not names.
